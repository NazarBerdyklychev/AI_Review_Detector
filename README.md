# Детектор AI-сгенерированных отзывов

Бинарная классификация текстов: определение, написан отзыв человеком (класс 0, `OR`) или сгенерирован нейросетью (класс 1, `CG`). 

Основная цель - исследовать, как объем обучающих данных влияет на качество простого лексического подхода (TF-IDF + LogReg) и полноценного трансформера (DeBERTa-v3-base) и сравнить их. Строится кривая ROC-AUC и оценивается, меняется ли разрыв между моделями с ростом выборки.

## Данные

Используется датасет `Flowerly/modern-fake-reviews` с HuggingFace. 
* Английский язык, 40 424 сбалансированных отзыва.
* Сгенерированная часть создана моделью DeepSeek-v4-pro.
* В датасете есть готовые сплиты train/validation/test, которые не меняются. Подвыборки [500, 1000, 2000, 5000, 10000] формируются только из train.

## Структура

* `data.py` - загрузка датасета с HF, кеширование в `data/raw/`, маппинг `OR -> 0`, `CG -> 1`.
* `baseline.py` - обучение TF-IDF + LogisticRegression, выдача вероятностей.
* `train.py` - fine-tuning `DeBERTa-v3-base`.
* `scaling.py` - формирует подвыборки, обучает обе модели, подбирает порог на validation, пишет `scaling_results.json`, сохраняет финальную BERT-модель и метрики на test.
* `predict.py` - CLI для инференса на сохраненной модели.
* `analysis.ipynb` - **графики** по результатам (scaling-кривая, confusion matrix, распределение вероятностей) и **выводы**.

## Запуск

```bash
pip install -r requirements.txt

# Обучение и сбор артефактов (займет время)
python scaling.py

# Графики
jupyter notebook analysis.ipynb

# Проверка на своём отзыве
python predict.py --text "This product is absolutely amazing!"
```
